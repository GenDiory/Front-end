switching the Lab 1 substructure

the first version in jQuery:
1. Open the file 'jquery.html ' by clicking on it twice or in the browser
2. then click on the button - the background of the text will turn yellow, one more click - the color will disappear/it will turn off 


the second version on React 
I did it on version v24.13.0
1. open the folder in the source code or in any other program
2. go through the 'cd react-toggle' command to the project itself
3. type 'npm install' in the terminal
4. then run everything the same way through the terminal with the command 'npm run dev'  
There will be a link in the terminal, open it in a browser
Click on the button to change the background of the text to yellow, to turn off the backlight, click again
